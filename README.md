# Taiwan Alpha Radar V13.1｜白話決策版

V13.1 延續 V13 的全市場掃描、歷史相似走勢、基本面與法人資料，但把首頁改成「先看結論，再看模型」。目標是讓推薦卡不用理解量化術語，也能快速回答：**這家公司做什麼、目前值不值得看、為什麼、現在要等什麼、風險在哪裡。**

## V13.1 新增

1. **細產業定位**：推薦標的名稱旁直接顯示通俗細產業，例如：
   - 台積電：半導體－晶圓代工龍頭
   - 鴻海：電子中游－EMS/垂直整合
   - 華城：重電綠能－變壓器外銷
   - 台達電：電子中游－電源與冷卻系統
   - 奇鋐、雙鴻：電子中游－水冷散熱
   - 其他未人工建檔股票會回到較保守的產業鏈標籤，不會硬猜過細分類。

   細產業是本模型的「通俗產業定位」，不是 TWSE/TPEx 官方分類。

2. **投資總評**：每檔股票先顯示白話結論，例如「偏多｜可優先觀察」、「偏多｜等便宜一點」、「偏多但過熱｜不要追高」、「轉弱｜暫緩」。

3. **推薦理由與風險**：自動整合以下訊息，最多顯示 3 個主要理由與 2 個主要提醒：
   - 最近是否比大盤強；
   - 過去類似走勢上漲比例及中間結果；
   - 月營收 YoY / MoM；
   - EPS 是否改善；
   - 毛利率是否高於近四季平均；
   - 近一月三大法人買賣超；
   - 大盤目前偏多、震盪或偏弱。

4. **主畫面去術語化**：
   - 「alpha」→「近20日比大盤」
   - 「historical positive rate」→「類似情況上漲比例」
   - 「effective N」→「可比歷史案例」
   - 「expected shortfall」→「較差情況平均跌幅」
   - 綜合分數、技術分、歷史模型分等仍保留，但移到展開後的「進階｜模型分數拆解」。

5. **公司資訊仍完整保留**：最新月營收（億元、MoM、YoY）、近 12 月營收、近 4 季 EPS／當年度累積 EPS、毛利率、PER、近月三大法人、可選券商分點主力代理。

## V13 核心仍保留

- 全上市櫃母池先做流動性檢查，再預排序，不以交易所回傳順序截前 300 檔。
- 3y/5y/8y/10y 歷史研究長度實際生效。
- Yahoo 多年日線後，再以 TWSE/TPEx 官方盤後資料補最新交易日。
- 報酬估計使用同一檔股票歷史上相似狀態的後續 10/40/120 交易日實現報酬，不把近期漲幅直接複利外推。
- TOP 5 採相對排名，不會因單一門檻太嚴而整頁沒有推薦。
- 個股診斷抓不到資料時明確回傳 unavailable，不塞固定假分數。
- 基本面與法人資料會真的進入完整模式的排名權重。

## 安裝與啟動

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows 可直接雙擊 `INSTALL_AND_RUN.bat`。

## 主力代理（選用）

「主力」不是交易所正式投資人分類。V13.1 只有在取得 FinMind Sponsor 券商分點資料時才做分點集中度代理；沒有權限時顯示未啟用，不會拿三大法人代替。

若有權限，可設定：

```powershell
$env:FINMIND_TOKEN="你的 token"
$env:ENABLE_BRANCH_FLOW="1"
python -m streamlit run app.py
```

## EPS 注意事項

FinMind `TaiwanStockFinancialStatements` 的 EPS 為單季值。介面的「當年度累積 EPS」為單季直接加總；若期間有配股或股票分割，可能和公司正式財報列示的追溯調整後累積 EPS 不同，因此只作為研究輔助。

## 離線自我測試

```bash
python self_test.py
```

測試包含：
- 3y/8y Yahoo 歷史參數轉換；
- 10/40/120 日歷史相似走勢模型；
- 進場區與防守價合理性；
- 月營收、EPS、毛利率、PER、法人資料解析；
- 綜合排序 0–100 邊界；
- 細產業分類；
- 白話投資總評與推薦理由。

## 資料來源

- TWSE OpenAPI：上市股票、盤後收盤、加權指數。
- TPEx OpenAPI：上櫃股票、盤後收盤。
- Yahoo Finance / yfinance：多年日線歷史。
- FinMind v4：月營收、財報、PER、三大法人；Sponsor 權限可另提供券商分點資料。

本工具為研究與決策輔助，不是保證報酬或自動下單系統。
